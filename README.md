### 🚀 Featured — hookproof

> **Verify Stripe · GitHub · Slack · Shopify · Discord · Svix webhooks with one call.**
> Zero dependencies, Web Crypto only, timing-safe. Runs on Node, Bun, Deno, Cloudflare Workers & Vercel Edge.

```bash
npm install hookproof
```
